# Datalayer

Cloud-based execution with full isolation, GPU support, snapshots, and persistence.

- **Requirements:** `code-sandboxes[datalayer]` (installs `agent_runtimes`).
- **Parameters:** `token` (defaults to `DATALAYER_API_KEY`), `run_url`,
  `snapshot_name`, `environment`. `gpu=` selects the `python-gpu-env`
  environment when the named environment is not already a GPU one — the card
  name itself is not sent, and neither are `cpu` and `memory`: the environment
  is what decides the machine.

## How To Obtain Datalayer Credentials

1. Create an account at [datalayer.ai](https://datalayer.ai).
2. Generate an API token from your account settings (**IAM → Tokens / API Keys**).
3. Export `DATALAYER_API_KEY` (or pass it as the `token` parameter). For a
   self-hosted or custom deployment, pass `run_url=` to `Sandbox.create()`:
   `DATALAYER_RUNTIMES_URL` is read only when listing the environments a
   provider ships, never when creating a sandbox.

## Usage

```python
import os
from code_sandboxes import Sandbox

os.environ["DATALAYER_API_KEY"] = "your-datalayer-token"

with Sandbox.create(
    variant="datalayer",
    environment="python-gpu-env",  # the environment is what carries the GPU
) as sandbox:
    sandbox.run_code("import torch; print(torch.cuda.is_available())")
```

## Network

A Datalayer sandbox reaches **any public host on ports 80 and 443 only**: pip,
npm, `git` over https and web APIs work; SSH, SMTP, raw TCP and any other port
are refused. The platform's own services stay reachable as before.

To reach a host on another port, name it with its port in `allowed_hosts`, for
that one sandbox (at most 20):

```python
with Sandbox.create(
    variant="datalayer",
    allowed_hosts=["github.com:22", "db.example.com:5432"],
) as sandbox:
    sandbox.run_code("import socket; socket.create_connection(('github.com', 22), 5)")
```

Each entry is `host:port` or `address:port`: an exact public host name or a
public IPv4 address. The platform refuses the launch, saying why, for an entry
without a port, a wildcard (`*`, `*.example.com`), a CIDR, an IPv6 address, a
private, loopback or link-local address (the cloud metadata address
`169.254.169.254` among them), a cluster or private name (`*.svc`,
`*.cluster.local`, `localhost`, `*.internal`), or a name that resolves to such
an address. The hosts are recorded on the runtime and shown by `list`.

`network_policy` stays at `inherit`: `none`, `allowlist` and `all` cannot be
honoured by a Datalayer sandbox and are refused before anything is launched.

The concrete implementation lives in its own subpackage (and is re-exported
from `code_sandboxes`):

```python
from code_sandboxes.sandboxes.datalayer import DatalayerSandbox
```

## Snapshots

Save and restore sandbox state (datalayer only):

```python
with Sandbox.create(variant="datalayer") as sandbox:
    # Set up environment
    sandbox.run_code("import pandas as pd")
    sandbox.run_code("df = pd.DataFrame({'a': [1,2,3]})")

    # Create snapshot
    snapshot = sandbox.create_snapshot("my-setup")
    print(f"Snapshot: {snapshot.id}")

# Later: restore from snapshot
with Sandbox.create(
    variant="datalayer",
    snapshot_name="my-setup"
) as sandbox:
    result = sandbox.run_code("print(df)")  # State restored
```
